# 🎨 Icon-Creator

Application Windows portable pour créer des icônes. Portable Windows app to create icons.

## ⬇ Télécharger / Download
**[Icon-Creator-portable.zip — dernière version / latest release](https://github.com/Walmes1/icon-creator/releases/latest)**

1. Dézipper / Unzip
2. Lancer / Run `Icon-Creator\Icon-Creator.exe` — aucune installation / no installation needed

> ⚠️ Windows SmartScreen peut afficher « Éditeur inconnu » (l'exe n'est pas signé) : *Informations complémentaires → Exécuter quand même*.
> Windows SmartScreen may warn "Unknown publisher" (unsigned exe): *More info → Run anyway*.
